# FastDrop

Быстрая передача файлов по локальной Wi-Fi сети (iOS 16+, SwiftUI).

* Обнаружение устройств — Bonjour (`_fastdrop._tcp`), IP можно ввести и вручную.
* Передача — TCP, порт `14680`, чанки по 1 МБ, несколько файлов подряд.
* Приём — в `Файлы → На iPhone → FastDrop` или в выбранную папку (Настройки).

## Протокол (v1)

1. Отправитель подключается к `ip:14680` и шлёт `[UInt32 BE длина][JSON FileHeader]`
   (`version, name, size, index, count, sender`).
2. Получатель отвечает 1 байтом: `1` — принять, `0` — отклонить.
3. Отправитель шлёт ровно `size` байт файла.
4. Получатель сохраняет файл и отвечает 1 байтом `1`.

Один файл — одно TCP-соединение.

## Сборка

* Xcode: открыть `FastDrop.xcodeproj`, выбрать Team, запустить.
* Новые `.swift`-файлы: `python3 scripts/generate_xcodeproj.py` (или добавить в Xcode вручную).
* CI (`.github/workflows/build-ios.yml`) генерирует проект и собирает unsigned `.ipa`.

## Важно

* При первом запуске iOS спросит доступ к локальной сети — его нужно разрешить.
* Приложение принимает файлы только на переднем плане (ограничение iOS).
